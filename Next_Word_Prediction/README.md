# 🔮 Next Word Prediction

A web-based **Next Word Prediction** application that uses the **GPT-2 language model** to generate intelligent, context-aware word suggestions in real time. The application provides an interactive interface where users can enter text and receive predicted next words, helping improve typing efficiency and writing flow.

### 🚀 Features

* Real-time next-word suggestions
* Context-aware text prediction using GPT-2
* Interactive and user-friendly web interface
* Flask-based backend for model integration

### 🛠️ Technologies Used

**HTML | CSS | JavaScript | Python | Flask | HuggingFace Transformers | GPT-2**

### 🧠 How It Works

The user enters a sentence or text through the web interface. The Flask backend processes the input and uses the pre-trained **GPT-2 model** from HuggingFace Transformers to predict suitable next-word suggestions, which are then displayed to the user.
